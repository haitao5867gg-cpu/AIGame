# 世界氛围

第一版以「外门杂役录」为样板。玄幻世界可用同一组器乐配乐；只有明确的田间室外地点展示灵田底图，室内与未知地点保持原有中性界面。其他题材暂不套用这套素材。

## 玩家操作

顶栏 ♩/♫ 控制声音，桌面地点行和手机「⋯ → 氛围设置」打开设置。背景、音乐音量、环境音量分别控制，音乐模式可选跟随场景、田间日常、外出探索、遇险。设置按玩家保存在既有 `prefs.json`，不修改世界存档。

初始背景开启、声音关闭，音乐默认 16%、环境音默认 10%。浏览器每次新开页面仍需一次明确点击解锁声音，保存的开启意愿不绕过这个限制。静音/退出世界立即停播；切到后台暂停，返回尝试恢复，被浏览器拦截时显示“点一下恢复声音”。音源失败有状态提示和手动重试，不循环请求或反复弹错。

## 数据与选择

`AtmosphereState.resolve(publicState, {scene, narration, prefs})` 返回固定 DTO：`worldId/theme/background/period/mood/ambience/location`。协调器只传当前世界和玩家已经看到的回合正文；旧世界异步响应不得切换当前氛围。选择器不修改状态，不调用模型，不使用 omen、apex、导演倒计时或 NPC 私密意图。

| 输入 | 输出规则 |
|---|---|
| 私下、社交、休息、亲密意图 | 优先平静配乐；不因后台事件变紧张 |
| 公开伤势危险或场景已发生交战 | 遇险配乐；不根据预告、传闻、回忆提前切换 |
| 真实探索/旅行意图 | 探索配乐；连续做同一件事不强制换曲 |
| 明确田间室外地点 | 灵田背景、风声；深夜可加虫鸣 |
| 正文明示正在下雨 | 雨声优先，最多两路环境音；雨中不叠虫鸣 |
| 室内或明确无声 | 不播田野风虫；室内只有正文明确可听见雨时才有雨声 |
| 无法确定 | 中性背景和平静配乐，不猜测新地点或剧情 |

时段来自游戏时钟，底图只调整明暗色调。手动选音乐模式优先于自动规则。文字分类是保守规则，不是全量语义理解；新发现的具体误判应补输入回归。

## 播放与保存

`AtmosphereAudio.create` 创建一组可重用的三个 HTMLAudioElement。用户点击时同时解锁 AudioContext 和播放；优先用 GainNode 调音量，兼容回退到媒体音量。普通回合保持同曲播放位置；换曲先约 0.8 秒淡出、再约 0.4 秒淡入。整段朗读会话持续让声到 20%，暂停/结束恢复，避免分段间忽大忽小。每路同时受用户音量与让声系数约束；环境总音量在当前两路之间分摊。

播放器用代次与通道令牌忽略过期播放 Promise/切歌计时器。静音、离开、账号切换和销毁都会暂停或清理相应资源；隐藏页面不新加载音频。设置弹层有滚动锁、焦点约束、Escape 关闭及关闭后焦点恢复。

偏好形状：`{background:true, enabled:false, musicVolume:0.16, ambienceVolume:0.10, mode:'auto'}`。服务端只接收合法字段，有限数值夹在 0..1，部分修改保留其他偏好/其他玩家。前端串行保存合并补丁；API 返回 `{prefs:{atmosphere:...}}`，旧响应不能覆盖新编辑或另一个玩家。

## 素材与传输

固定目录 `public/assets/atmosphere/catalog.json` 列出版本化相对路径，游戏正文不能提供音源 URL。三首器乐和三段自然音效总约 12.8 MB，底图 JPEG 约 351 KB；未解锁时不设置音频 src，播放时只请求当前所需文件，不整包预下载。每回合不增加模型或出图请求。

静态音频按单段字节范围流式响应，支持 GET/HEAD、206/416，并在客户端中断时销毁源读流；空文件无 Range 返回 200 空体。仅氛围目录使用 `private, max-age=86400`，既有静态资源继续 `no-cache`，认证门禁不变。目录更新通过版本化文件名避免旧素材缓存；协调器对目录本身使用 `cache:'no-cache'`。

完整署名、来源、许可链接与修改说明见 [CREDITS.md](../public/assets/atmosphere/CREDITS.md)，同样呈现在设置的「素材致谢」。灵田底图使用内置图像生成工具制作，按既有工笔重彩画风，仅做 JPEG 压缩；最终提示词与原图保留在本地验收目录，不进入运行数据。

## 验证与交付边界

运行 `node scripts/testsum.js` 完整回归，或指定上述五个氛围测试文件。HTTP 回归使用真实素材字节，不请求任何 AI 服务；音频单测验证自动播放拒绝、错误重试、淡切竞态、独立静音、让声及后台/离开清理。

界面验收只使用 `LLM_MOCK=1 TUNNEL=off IMAGE_PROVIDER=off HOST=127.0.0.1 PORT=8798 DATA_DIR=reports/atmosphere-20261108/mock-data node server.js`，本地模拟存档与线上隔离。验收记录/截图保存在 `reports/atmosphere-20261108/`。桌面与手机尺寸浏览器检查不等同于实体 iPhone 或 Android 的兼容认证，后台生命周期另以控制器和协调器测试覆盖。

本功能没有世界数据迁移，也不重生成玩家剧情。部署仍须用户本次明确说「可以部署」，上线后需保留素材署名。
